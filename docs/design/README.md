# Handoff: JobFlow — дизайн-система, веб і мобілка

## Overview
JobFlow — трекер пошуку роботи для IT-фахівців українського ринку: kanban відгуків, AI-розбір вакансій, нагадування про фоллоу-апи й глибока аналітика воронки. Пакет містить дизайн-систему (22 розділи), 7 веб-екранів, мобільний компаньон і єдине джерело токенів.

## About the Design Files
Файли в цьому пакеті — **дизайн-референси, зроблені в HTML**: прототипи, що показують задуманий вигляд і поведінку, а **не продакшн-код для копіювання**. Завдання — **відтворити їх у кодовій базі** на стеку з брифу: Next.js + React + TypeScript + Tailwind + shadcn/ui (веб) і Expo + NativeWind (мобілка), використовуючи бібліотеки, перелічені нижче.

Відкривати `.dc.html` можна прямо в браузері (поруч має лежати `support.js`). Почніть з `JobFlow - Система.dc.html` — це індекс, звідти посилання на всі екрани.

## Fidelity
**High-fidelity.** Кольори, типографіка, відступи, радіуси, тіні, стани й анімації — фінальні. Відтворювати піксель-у-піксель.

## Порядок роботи (рекомендований)
1. `tokens.json` → згенерувати `tailwind.config.ts`, `theme.ts` (NativeWind), `chart-theme.ts`.
2. Спільні компоненти (розділ 22 дизайн-системи): `Button`, `Field`, `Select`, `ScoreBadge`, `StageChip`, `OutcomeBadge`, `ApplicationCard`, `SilenceIndicator`, `EmptyState`, `AsyncState`.
3. Екрани в порядку плану: Дашборд → Канбан + модалка причини → Карточка вакансії → Додавання (F1) → Резюме/налаштування/вхід → Порожні стани.
4. Мобілка останньою — за розділом 21 «RN-шар».

## Design Tokens
**Повний набір — у `tokens.json`** (джерело правди). Кожен колір має пару `oklch` (веб) + `hex` (RN, Chart.js). Ключові:

| Токен | oklch | hex | Призначення |
|---|---|---|---|
| paper | 97.4% .007 78 | #F9F6F1 | тло застосунку |
| surface | 99.4% .004 85 | #FEFDFA | картка, поповер |
| surface-2 | 97.2% .006 80 | #F8F5F1 | тло поля |
| line | 91% .008 78 | #E4E1DB | межа контрола |
| ink | 25% .013 62 | #26201B | текст · 13.1:1 |
| ink-3 | 50% .012 68 | #68625C | підпис · 4.9:1 — нижня межа контрасту |
| accent | 52% .12 252 | #2D6BAB | дія, фокус |
| offer | 49% .10 158 | #20714A | коло заповнене |
| rejected | 58% .09 34 | #A96656 | коло з рискою (терракота, не червоний) |
| ghosted | 78% .014 78 | #BCB6AE | коло пунктиром |
| withdrawn | 58% .035 275 | #747990 | коло з косою |

Темна тема — секція `dark` у `tokens.json` (14 токенів, тепла база).

**Шрифти:** Unbounded (заголовки, великі цифри) + Onest (інтерфейс). Обидва OFL, Google Fonts / `@expo-google-fonts/*`. `tabular-nums` на всіх числах.

**Контроли:** висоти 28 / 32 / 36 / 42, радіуси 8 / 8 / 9 / 10. Клікабельна зона ≥ 44px.

**Шари (замість обведень):** flat (inset-кільце 1px) / e1 картка / e2 меню / e3 модалка / accent / focus (кільце 2+2). Точні значення веб і RN — у `tokens.json → elevation`.

**Рух:** 140 / 180 / 200 / 260 (spring) / 820 (дані, stagger 45ms), easing `cubic-bezier(.2,.8,.3,1)`. `prefers-reduced-motion` вимикає все.

## Interactions & Behavior — ключові правила домену
- Відсоток показується лише на вибірці ≥ 5; висновок — від 10; прогноз — від 15. Нижче — «скільки ще бракує».
- Ghost не входить у розрахунок конверсій.
- Відмова ніколи не червона: червоний зарезервований під системні збої.
- Стан ніколи не тільки кольором: колір + форма маркера + підпис.
- Кожна AI-операція має 4 стани: у черзі / обробляється / готово / помилка.
- Match Score без CV — пунктирний прочерк, не нуль.
- Кожен ховер має пару `pressed` для RN; фокус-кільце ніколи не знімається.
