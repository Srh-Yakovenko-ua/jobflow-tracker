Перевірено програмно: контраст тексту WCAG AA — 0 порушень, тач-таргети в мобілці — 0 менших за 44pt, усі 7 чартів дашборда відмальовані, іконок-плейсхолдерів немає, консоль чиста.
технічна рамка Next.js + Tailwind на вебі, Expo + NativeWind на мобілці, один tokens.json як джерело обох тем. Бібліотеки: dnd-kit — дошка, Chart.js — графіка, TanStack Table — таблиці, FullCalendar — сітка календаря, lucide — іконки. Розділ 21 · RN-шар у системі описує, що з цього переноситься в мобілку, а що підмінюється: hex-токени, тіні через elevation, pressed замість hover, victory-native і FlashList замість веб-бібліотек.
